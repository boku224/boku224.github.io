# boku lylack 個人ページ

GitHub Pages で公開する静的サイト（ビルド不要）。

## 編集する場所

- リンク・アイコン画像・メールアドレス: `script.js` 冒頭の設定
- 文章: `index.html`
- 色: `style.css` の `:root`

アイコン画像は `assets/avatar.png` などに置き、`script.js` の `AVATAR` にパスを書く。

## 公開

`main` ブランチに push すると GitHub Pages に反映される（Settings → Pages → Branch: `main` / `(root)`）。
